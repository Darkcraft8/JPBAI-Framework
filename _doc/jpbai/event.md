### Behavior Event
  This Document need to be filled with more detail

#### `monster`
    This eventType will spawn a monster

#### `projectile`
    This eventType will spawn a projectile

#### `function`
    This eventType will execute a function while passing up to 10 args
#### `setCursor`
    This eventType will set the user cursor

#### `damageArea`
    This eventType will set a damageArea for the item

#### `playSound`
    This eventType will play a sound that is present in the item effective animation config (animation + animationCustom)
